## 第 1 批：顶部导航 / 左侧图标栏 / 算小维面板（preview/src）

### 顶部导航 top-nav
1. Logo 不是彩色圆环：设计稿是一个**蓝色分子状图标**（3 个大小不一的圆点：左下浅蓝 #6FB8FF 小圆、中间蓝 #2F7BFF 大圆、右上深蓝 #1E5BFF 小圆，用细线相连），24px。
2. 「iMaster CCAE」：20px，字重 500（不要粗体），#1F2329，字母间距 0.2px。
3. 「智能模式 ▾」胶囊：浅紫渐变底（#E9E3FF → #DCE6FF），文字和图标 #7A5CFA，左侧带 ✦ 星芒小图标，高 24px，圆角 12px，13px。不要实心深紫。
4. 右侧图标：月亮、用户，均为 20px 细线图标 #4A4F5C，**用户图标不要外圈**。

### 左侧图标栏 side-nav

## 第 2 批：指标卡 / 机柜区工具栏 / 时间轴（preview/src）
1. 指标卡距顶部导航 24px；三段宽度：基础设施区占卡片宽 70%，训练作业、推理服务各约 15%（分割线位置向右移）。段标题 17px 字重 600。
2. 机柜区右侧工具按钮：合并成**一个竖向白色面板**（宽 40px，圆角 10px，阴影 0 4px 12px rgba(0,0,0,0.08)，内边距 6px），从上到下：刷新、3D 立方体（**选中态**：浅蓝底 #E8F0FF + 蓝色图标）、展开/全屏、＋、－、「100%」（11px 灰字）。图标 16px #6B707A，间距 12px。不要 6 个独立方块。
3. 时间轴图例图标全部改为**实心**：待人工处理 = 实心红色手掌；自动处理中 = 橙→粉→蓝渐变的**空心圆环**（3px 环宽）；已闭环 = 深灰实心圆 + 白色对勾；影响到业务 = 橙色实心八角星。
4. 时间轴事件胶囊：灰色三角放在浅灰圆底（#F2F3F5，22px）里；故障为红色实心圆（22px）+ 白色三角；待人工徽标 = 白底 + 1.5px 红色描边圆（20px）+ 实心红手掌；12:04 那组的小胶囊里手掌和八角星均为实心。

## 第 3 批：3D 机柜外观（preview-3d/src，用 build-3d.mjs）
1. **机柜正面纹理**：设计稿是「竖向条带」观感——每台机柜正面左右各有约 18% 宽的深色边框，中间 64% 宽是服务器面板区；面板区分 3 组，每组 6 条横向浅灰条（#8E97A3，条高:间隙 = 2:1）。这样整排看起来是一根根竖向的亮灰色条带被黑色竖缝分开。
2. 顶面颜色提亮到 #4B525C，侧面（行末右端）#2A2E34。
3. 每排机柜在地面上向**右后方**投一块浅灰色平行四边形阴影（rgba(0,0,0,0.07)，长度约为机柜高度的 0.8 倍，边缘柔化）。
4. 「Superpod X」标签：改为浅一些的半透明灰（rgba(70,75,85,0.72)），1px 描边 rgba(255,255,255,0.45)，文字白色 13px，「Superpod」与字母之间两个空格；标签底边**贴在**该排第 01 台机柜顶面左前角上方。
5. 编号文字随透视缩放：近排 11px，最远排 8px，并保持每个编号与其机柜中心对齐、相邻编号之间至少 2px 间隙（远排可只显示奇数编号之外的…不，全部显示，但字号缩小）。
6. A-08 顶部气泡：白色圆（直径约机柜宽 1.1 倍）+ 内部紫→蓝渐变实心三角；A-15、D-08 的定位针 = 白底圆 + 红色实心圆三角 + 右上角红底白手掌小圆徽标（徽标直径为定位针的 0.6 倍）。
