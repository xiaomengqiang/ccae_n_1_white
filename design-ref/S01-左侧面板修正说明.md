# S01 · 左侧算小维面板（ai-panel）修正说明

当前实现和设计稿差别明显，按下面逐条修改。只改 preview/src/views/ai-panel/（以及它用到的 mock / components）和 side-nav、top-nav 的 logo。

## 1. 算小维形象（最明显的问题）
- 设计稿用的是一张 3D 卡通男孩（黑色蓬松头发、黑框眼镜、蓝眼睛、双手扒在边沿往下看）的透明 PNG，已放在 `preview/assets/uploads/suanxiaowei.png`（160×160，透明背景）。
- 不要圆形头像框、不要描边、不要底色。直接显示图片，宽高约 150px。
- 位置：在面板右上区域，图片下沿压住下方「守护效果」白色容器的顶边（向下重叠约 20px），营造「从卡片后面探出头」的效果；图片层级在容器之上。
- 左侧气泡「算小维在岗，健康守护中～」垂直居中对齐头像的眼睛高度，气泡是白色半透明胶囊（rgba(255,255,255,0.85)，圆角 22px，高 44px，左右内边距 20px，轻阴影 0 4px 12px rgba(80,90,160,0.08)），「算小维」三个字用蓝→紫渐变文字（#5B8CFF → #A26BFA）。

## 2. 面板背景
- 面板背景改为浅色渐变：顶部浅蓝 #DDE8FB → 中部 #EEF1FB → 底部接近白 #F6F7FB；右上角加一团很淡的粉紫光晕（radial-gradient，rgba(200,170,255,0.35)）。

## 3. 「守护效果」白色毛玻璃大容器（当前缺失）
- 从「守护效果」标题开始，到事件列表结束，所有内容都放在一个大容器里：背景 rgba(255,255,255,0.55) + backdrop-filter: blur(12px)，1px 白色描边 rgba(255,255,255,0.9)，圆角 20px，内边距 16px，左右与面板边距 12px。
- 容器左上角是一个向上凸起的「标签页」形状，「守护效果」标题就在这个凸起里（可用一个单独的圆角块 + 伪元素做过渡曲线，凸起宽约 220px、高约 36px）。
- 「故障与隐患」「能效优化」两张卡片是容器里的白色卡片：背景 #FFFFFF 不透明度 0.85，1px 描边 #E6EAF5，圆角 12px，无明显阴影。

## 4. 守护效果正文
- 文字 14px #4A4F5C，行高 22px。
- 「8192卡」「13个训练作业」「16个推理服务」中的数字和单位用紫粉渐变（#7B6BFF → #E07BC4）。
- 「人工处理的资源事件需关注」用紫粉渐变文字；「2项」中的 2 用红色 #F0454A。

## 5. 两张指标卡片
- 标题行：左侧图标是圆形浅色底（故障=浅红底 #FDECEC + 实心红色三角感叹号；能效=浅绿底 #E6F7EE + 绿色闪电），标题 15px 加粗 #1F2329；右侧大数字 22px 半粗（66.2、86），单位 %、/128 用 12px 灰色 #8A8F99 紧跟在数字后；数字下方灰色小字说明；最右侧一个向上的折叠箭头 ^（不是下拉箭头），点击可收起卡片。
- 副标题：「故障恢复 3/15」中的 3 用红色；「隐患处理 0/18」灰色。「节能中」灰色（不要绿色）。
- 卡片内分隔：标题行与指标区之间有一条 1px #EEF0F5 分割线。
- 指标数字：「作业可用度」等标签 12px #8A8F99；数值 26px 常规字重 #1F2329（如 99.54），单位 % 或 kWh/Mtoken 12px 灰色，和数字底部对齐。
- 迷你趋势线：改为非常平缓、细的线（1.5px，浅蓝 #7EA6F5），几乎是一条略有起伏的水平线，下面配极淡的蓝色渐变填充（opacity 0.08），高度约 16px。现在的波浪太大。
- 「中型模型·百万Token能耗」后面的红点放在文字末尾。

## 6. 智能体事件
- 分段切换：外层浅灰胶囊底 #EEF0F5、圆角 20px；选中项白色胶囊 + 轻阴影，文字深色，数字 3 红色；未选中「自动处理中 1」的 1 为深色加粗。
- 事件图标改为**实心**红色三角感叹号（#F0454A），标题 15px #1F2329，描述 13px #6B707A，时间 13px #6B707A。条目之间 1px #EEF0F5 分割线。
- 事件列表在白色毛玻璃大容器内部。

## 7. 底部输入框
- 高 48px，圆角 24px，白底；描边用渐变：左侧淡紫 #B9A8FF → 右侧橙粉 #FFB38A（可用 background-clip 双层背景实现 1.5px 渐变边）。
- 右侧发送按钮：直径 32px 圆形，浅紫渐变底（#C7D2FF → #E3C9FF），内部白色纸飞机图标；不要深紫实心圆。

## 8. Logo
- top-nav 和 side-nav 顶部的 logo 现在是机器人图标，设计稿是一个彩色圆形 logo（橙/红/黄/蓝四色旋转的圆环球体）。用 CSS 圆锥渐变 conic-gradient(#FF6A3D, #FFC53D, #3D8BFF, #FF4D7A, #FF6A3D) 做一个 24px 的圆，中间留一个 8px 白色小圆，近似即可。
