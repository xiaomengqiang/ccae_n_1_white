# 第 11 轮 · 第 2 批验收问题（preview-3d/src + cabinet-area）

实测：hover 提示卡 ✅、点击选中 ✅、刷新重置 ✅、工具条 tooltip ✅、拖拽有限制 ✅。问题如下：

## 1. 缩放方向反了（P0）
- 点「＋」两次：阵列反而**变小**，同时数字显示 110%；连点到上限后阵列缩成一小块。
- 左侧点事件「光链路脏污」触发 focusCabinet(A-15)：画面也是**缩小**而不是放大到 A-15。
→ 统一定义 zoom = 画面放大倍数：zoom 越大，机柜越大（相机越近 / fov 越小）。＋ = zoom+10%，－ = zoom−10%，滚轮向上 = 放大。范围 70%–160%，显示值与实际一致。
→ focusCabinet：相机 600ms 缓动，使目标柜位于 3D 视口中心，zoom = 130%，然后目标柜呼吸高亮 2 次。

## 2. 水平旋转幅度仍偏大
±20° 时阵列已经明显斜成对角线、A 排冲出画面下沿。→ 水平限制改为 **±10°**，俯仰 −4°/+6°；旋转中心为阵列几何中心。

## 3. 全屏（展开按钮）
- 进入全屏后相机没有重新适配，G/H 两排被裁到画面上方之外；右上角也没有「退出全屏」按钮。
→ 进入/退出全屏时按新视口尺寸重新 fit（保持与默认相同的构图：8 排全部可见、阵列居中，四周留白比例与默认一致）。
→ 全屏时右上角显示「退出全屏」按钮（白底圆角 6，12px #191919，带缩小图标），点击或 Esc 退出；退出后恢复默认视角和 100%。
→ 全屏时工具条跟随到视口右侧，仍可用。

## 4. 选中态太弱
点击后几乎看不出选中了哪台。→ 选中柜正面叠加 rgba(47,123,255,0.18)，四周 2px #2F7BFF 描边，顶部蓝色小定位针保持；提示卡固定。

完成后 build-3d + build + verify，简短回复后停下。
