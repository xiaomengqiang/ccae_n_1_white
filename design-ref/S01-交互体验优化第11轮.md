# S01 · 交互体验优化（第 11 轮）

我在 1920×1080 和 1366×768 下逐项实际操作过一遍。视觉已接近设计稿，但**几乎所有看起来能点的东西都没有反应**，个别地方体验有明显 bug。下面按优先级分 3 批，每批做完 build + verify 后停下。
原则：**不改变静态视觉**（默认状态截图必须与现在一致），只增加 hover/选中/反馈状态。所有可点元素 cursor:pointer。动效统一 200ms ease-out。

---

## 第 1 批：左侧算小维面板（preview/src/views/ai-panel）

### 1.1 输入框（bug，P0）
- 现状：输入文字后占位符「输入问题或输入"/"触发提示词」**仍然显示，与输入文字重叠**；回车/点发送都没反应。
- 改：用真实 `<input>`（透明背景，叠在 input-box@2x.png 上，left 18px，14/22 #191919），占位符用 input 的 placeholder 属性（#AEAEAE），有内容即隐藏。focus 时不加浏览器默认 outline。
- 回车或点右侧发送按钮（热区：输入框右侧 36×36 圆）→ 在输入框正上方弹出「算小维回答卡」：
  - 白底、圆角 12、阴影 0 8px 24px rgba(40,60,120,0.12)，宽 444，左对齐输入框，最大高 280 可滚动，右上角 × 关闭，Esc 也可关闭；
  - 第一行用户问题（14 Medium #191919），下方先显示 600ms「算小维思考中…」三点动效，再显示 mock 回答（14/22 #555）；
  - mock：问题含「A-15」→「A-15（SuperpodA · 计算柜15）检测到 NPU 故障，已自动隔离 2 张卡，训练作业已迁移，当前等待人工更换。」+ 蓝色文字按钮「在机房中定位 →」；含「D-08」→ 类似文案；其他 → 「当前集群整体健康，2 项待人工处理事件需关注。」
  - 点「在机房中定位」→ 调用 3D 定位（见第 2 批 2.4 的 postMessage 协议，第 1 批先把消息发出去即可）。

## 第 2 批：3D 机柜区交互（preview-3d/src + preview/src/views/cabinet-area）

### 2.1 拖拽太自由（P0）
- 现状：拖动 150px 整个阵列就转了约 40°，没有任何限制，排布很快乱掉且回不去。
- 改：水平旋转限制在默认视角 ±20°，俯仰限制在默认俯角 −6°/+10°；拖拽灵敏度降到现在的 1/3，开启阻尼（damping 0.12）；滚轮缩放限制在 70%–160%。

### 2.2 hover 机柜无反馈（P0）
- hover 某台机柜：该柜正面提亮（emissive 叠加 #2F7BFF 强度 0.25）+ 顶面出现 1px #2F7BFF 描边；鼠标旁出现提示卡（DOM 覆盖层，白底圆角 8，阴影，padding 10/12）：
  - 第一行「A-05」14 Medium + 状态标签（正常=绿 / 故障=红 / 节能=灰）；
  - 下面两行 12 #777：「NPU 利用率 76%」「功耗 12.4 kW」（mock 随机但固定）。
- 移出后 150ms 消失。

### 2.3 点击机柜（P1）
- 点击：选中态（正面蓝色 2px 描边 + 顶部蓝色小定位针），提示卡固定显示并增加「查看详情 →」链接；点空白处取消选中。

### 2.4 主页面 ↔ 3D 通信（P0，供第 1、3 批使用）
- 主页面 → iframe：`{type:'focusCabinet', id:'A-15'}`：相机 600ms 缓动到以该柜为中心、放大到 130%，柜子做 2 次呼吸高亮；`{type:'reset'}`；`{type:'zoom', step:+1|-1}`。
- iframe → 主页面：`{type:'zoomChanged', value:110}`。

### 2.5 右侧工具条（P0）
- 现状：5 个按钮点击全部无反应，「100%」不变。
- 刷新 = 重置视角（600ms 缓动回默认）；＋/－ 每次 ±10%（范围 70–160%），「100%」文字实时更新；展开 = 机柜区进入全屏（覆盖右侧主区 x 548–1904、y 48–1080，右上角出现「退出全屏」按钮，Esc 退出）；立方体 = 保持选中态（本轮不做 2D）。
- 每个按钮 hover：28×28 圆角 6 背景 rgba(0,0,0,0.05) + 左侧 tooltip（深色 #1F2329 白字 12px）。

## 第 3 批：时间轴 / 指标卡 / 深色模式 / 视觉细节

### 3.1 时间轴事件胶囊（P1）
- hover：胶囊上移 2px + 阴影加深；上方出现提示卡：「12:00:40 光链路脏污，待清污」「计算柜11 · 待人工处理」。
- 点击：左侧对应事件条目选中 + 3D 定位到对应柜（12:00 → A-15，12:04 → D-08）。

### 3.2 指标卡（P2）
- 每个指标项（图标+文字整块）hover 背景 rgba(0,0,0,0.03) 圆角 8，cursor pointer；点「故障数 2」→ 左侧切到「待人工处理」并让 3D 依次闪烁 A-15、D-08。

### 3.3 深色模式（P0，目前是坏的）
- 现状：点月亮后只有主区变黑，顶栏图片仍是白色、左侧面板仍是浅色、训练/推理的小图标变成黑色实心圆、3D 区仍是浅灰——整页割裂。
- 设计稿没有深色版本，本轮**不实现深色**：点月亮改为在图标下方弹出轻提示「深色主题设计中，敬请期待」（2s 自动消失），页面不变。

### 3.4 视觉细节
- 3D 容器左右和底部有一圈淡淡的圆角边（设计稿没有），去掉容器的边框/圆角/背景差异，和页面无缝融合。
- 机柜正面百叶条纹对比仍略强：缝 alpha 0.30 → 0.22，亮条 #949EAA→#7A8490 改为 #8E98A4→#78828E。
- G 排最右端 2 台、H 排最左端 2 台的侧面露出过多显得「散开」：这两排两端机柜侧面颜色压暗到 #1E2226，与正面黑边融为一体。
- 1366×768 下 3D 里的编号（01–20）缩放后只有 ~6px 看不清：编号字号随页面缩放做下限补偿，保证实际屏幕像素 ≥ 8px。
