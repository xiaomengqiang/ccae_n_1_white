参考图：design-ref/S01-智能首页.png 中间区域（如果模型读不了图片，以本文为准，本文已把图里的视觉信息全部写成文字和数值）。
工程：只改 preview-3d/src/（主要是 hooks/use-three-scene.js 和 views/scene-viewport/），用 `node .opencode/skills/ict-coder/scripts/build-3d.mjs --dir "preview-3d"` 构建，再 verify-build。three.js 是 r147。

## 1. 场景总体
- 背景：浅灰 #EDEEF2 → 底部稍亮 #F4F5F7 的竖向渐变（可用 CSS 背景 + renderer alpha 透明）。**不要地面网格**，地面只要一层很淡的阴影/反光即可。
- 机柜阵列：8 个 Superpod，排成 **4 排 × 2 列**，每个 Superpod 是一排 20 台机柜并排（编号 01–20，从左到右）。
- 排布（由远到近）：
  - 第 1 排（最远）：左 Superpod G，右 Superpod H
  - 第 2 排：左 Superpod E，右 Superpod F
  - 第 3 排：左 Superpod C，右 Superpod D
  - 第 4 排（最近）：左 Superpod A，右 Superpod B
- 每排之间前后间距约 2.5 个机柜深度；左右两列之间留约 3 个机柜宽度的过道。
- 相机：透视相机 FOV 30–35°，从正前方略偏上俯视，俯角约 30°，水平几乎正对（略向右偏 5° 以内），使近处 A/B 两排占画面下半部、远处 G/H 在上方且明显变小。整个阵列在画面中居中、四周留白约 8%。
- 保留原有交互：拖拽环绕 + 滚轮缩放；**去掉待机自转**（设计稿是静止视角）。

## 2. 单台机柜外观
- 尺寸比例：宽 1 : 高 3.2 : 深 1.6（相邻机柜间留 2% 的缝）。
- 机身：近黑深灰 #1E2124，轻微金属感（roughness 0.6, metalness 0.3）。
- 正面：用 CanvasTexture 程序化绘制（不要用外部图片）：
  - 外框深色 #15171A，内部上 1/8 是一条窄的网口面板（细灰线 + 1 个小绿点指示灯 #3BD16F 在右上角）。
  - 下面是 3 组服务器刀片区，每组 6–8 条横向浅灰条纹（#8A9099 与 #5C626B 交替，条高约 3px，间隔 2px），组与组之间有一条深色分隔带。
  - 整体视觉是「黑色机柜里一排排亮灰色的横向服务器面板」。
- 顶面：深灰 #3A4048；**Superpod A 这一排的顶面例外**，从左到右做青灰 #3E5F63 → 紫色 #5B4A78 的渐变。
- 侧面：比正面更暗 #121417。
- 灯光：环境光 0.8 + 一盏从左上前方打来的平行光 0.6，让顶面比正面亮、侧面最暗。

## 3. 状态高亮（mock 数据）
- **A-08（自动处理中）**：这台机柜整体覆盖半透明竖向渐变发光：顶部橙 #FF8A50 → 中间粉紫 #C86BFA → 底部蓝 #6A8CFF，opacity 约 0.75，正面条纹仍隐约可见；柜顶上方悬浮一个白底圆形气泡（直径约机柜宽 0.9 倍），里面是橙紫渐变的三角警示图标。
- **A-15（故障，待人工处理）**：机柜覆盖半透明红色 #F0454A（opacity 0.7）；柜顶上方悬浮红色定位针图标（白底圆 + 红色三角警示），右上角叠一个红底白色「手掌」小圆徽标（代表待人工处理）。
- **D-08（故障，待人工处理）**：和 A-15 同样的红色样式和图标。
- **A-09 ~ A-12（节能中）**：正面条纹变暗（只保留很淡的轮廓 #3A3F46），表示服务器已下电节能。
- Superpod A 整排机柜底边下方，有一条贴地的彩色发光线：从左到右 青 #5ED6E8 → 紫 #A774FF，宽度约 3px，带轻微模糊。

## 4. 文字标签（用 HTML 叠加层，不要用 3D 文字）
- 每排左上角一个标签「Superpod X」：深色半透明圆角胶囊（背景 rgba(40,44,52,0.85)，1px 浅色描边 rgba(255,255,255,0.25)，圆角 6px，内边距 2px 10px），白色 13px 文字，「Superpod」和字母之间空一格。位置贴在该排第 01 号机柜顶面左上角。
- 每排机柜正下方一行编号 01–20，浅灰 #9AA0A8，11px，与对应机柜对齐。
- 特殊编号用小胶囊突出：A-08 用橙紫渐变边框 + 渐变文字；A-15、D-08 用红底 #F0454A 白字。
- 标签位置要每帧用 camera.project() 从 3D 坐标投影到屏幕，拖拽视角时跟着动。
